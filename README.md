# Weather App

A responsive weather application built for The Odin Project. Search for a location to view current weather conditions and switch between Fahrenheit and Celsius.

## Live Demo

[View Weather App](https://tranzcend3nce.github.io/Odin-Weather-App/)

## Features

- Search for current weather by location
- Toggle between Fahrenheit and Celsius
- Dynamic weather icons and colors
- Loading animation and error handling
- Responsive design for desktop and mobile

## Built With

- HTML, CSS, and JavaScript
- Webpack
- Visual Crossing Weather API
- Lucide Icons

## Getting Started

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm start` to launch the development server.
